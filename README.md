# PIXEL CLASH 像素衝突

瀏覽器遊戲大廳，提供海龜湯及 5v5 即時像素風開放世界死鬥。遊戲主機需要 Node.js 18 以上，玩家以瀏覽器連線即可。

開啟網站會先看到以遊戲地圖渲染的標題畫面。點 **TAP TO START** 或按 Enter 即可進入模式選單。
選擇 **像素衝突** 可進入 5v5 副本選單，**海龜湯** 則直接進入單人推理。

手機對戰拉遠鏡頭、縮小小地圖與道具圖示，橫向會將隊友頭像排成兩欄，隊伍聊天預設折疊，可點按展開。電腦版使用原有鏡頭與 HUD 版面。手機對戰時按住左下四分之一的戰場會從觸點叫出移動搖桿，放開即收起；點其他戰場區域可瞄準並普攻，也可按右下角的藍色劍圖示自動瞄準範圍內最近且未被地形阻擋的敵人，也可點技能或開箱按鈕。角色腳下的像素劍與進度條顯示普攻冷卻，生命條在下方道具欄上方。各角色的技能圖示下方顯示用途，游標停留 2 秒或手機長按 2 秒可查看技能說明。在遊戲中點擊任一處後才會播放背景音樂，音效開關可同時靜音。各場景有較低音量的戰鬥配樂，海龜湯會依題目切換旋律。翻閱圖鑑、開箱、使用道具、倒下和復活都有各自的音效。登入後，可在玩家帳號頁選擇本機照片作為頭像。網站只儲存裁切後的圖片。自訂頭像會顯示給等待大廳內的其他玩家，未設定時，每次進入等待大廳會從 20 張像素梗圖中隨機挑一張頭像，同房玩家會看到同一張。等待大廳加入 AI 時，會從 20 位《探險活寶》角色中隨機抽取名字及頭像，同房不重複。

## Windows 啟動

在 CMD 輸入：

```bat
cd /d C:\Users\user\Desktop\game-hub-main
npm install
npm start
```

開啟 [http://localhost:3000](http://localhost:3000)。要讓朋友從外部連線，保持主機與遊戲伺服器運作，在另一個 CMD 視窗輸入：

```bat
cloudflared tunnel --url http://localhost:3000
```

把 Cloudflare 顯示的 HTTPS 網址分享給朋友。Quick Tunnel 若回傳 HTTP 429，可先用 localhost 驗證遊戲是否正常啟動。Ollama API 應維持在主機本地，遊戲入口使用 3000 埠。

## 玩家帳號

點選模式選單右下方的 **登入／註冊**。註冊時自訂 3–24 個英數字元的帳號，至少各含一個英文字母和數字，英文大小寫視為同一個帳號。密碼需為 8–48 個字元。建立帳號後，用該帳號與密碼登入。登入後再點右下方的帳號即可登出。兩個遊戲模式仍可直接以訪客身分遊玩。

第一次登入後請設定全站唯一的玩家名稱。伺服器會分配固定的玩家 ID，由 2 個英文字母及 6 個數字組成。**好友**可用完整名稱或玩家 ID 送出邀請，對方接受後會互相出現在好友名單。

等待大廳可按 **邀請好友**。好友會在右上角收到 **對戰邀請**，可加入或婉拒。邀請有效 3 分鐘，須在房間尚未開局時使用。若房主邀請時已用 AI 補滿，好友接受後可直接接替一名 AI。房主開始選角時隨機分隊，每隊五人，兩隊真人數最多相差一位。重賽會重新抽隊。

登入並命名後可在 **成就圖鑑** 查看對戰與推理成就的解鎖狀態與獎勵。可用上一頁／下一頁按鈕或方向鍵翻閱魔法書。解鎖後可點彩色徽章查看條件和獎勵，未解鎖可看條件與進度。隱藏成就只提供提示，傳說成就達成後才出現。舊戰績也會計入可回溯的項目。圖鑑內的 **對局紀錄** 可查看已完成的對戰與海龜湯紀錄。點選紀錄查看完整比分、勝負、對局時長、雙方職業及 K/D/A、有效傷害與稱號。較早的對戰紀錄只有個人統計。海龜湯在找齊線索或揭曉答案時記錄題目、線索與提示使用量。提問階段下方會保留本題問答，換題時清空。

單一伺服器的帳號資料保存在 `data/accounts.json`（可透過 `PIXEL_CLASH_ACCOUNTS_FILE` 指定路徑），只儲存密碼的加鹽雜湊。重啟伺服器後帳號仍可登入，重啟前的登入狀態會失效。公開連線使用 HTTPS 網址，本機開發可使用 `http://localhost:3000`。

## 遊玩

- **海龜湯**可從首頁進入難度選單。選擇簡單、中等或困難，翻完兩頁漫畫前情後開始提問。題庫包含 17 題，其中新增四道懸疑題。漫畫頁可點「播放旁白」，使用裝置支援的中文語音。問題會依題目事實、同義詞與否定語氣判斷。若無法確認推論，主持人會請你補充而不是直接判成無關。每題有三次提示，也可重看漫畫、換同難度的新題或揭曉答案。
- **團隊對抗**由一名真人建立房間，其他真人可用房間代碼加入。房主可逐一新增、移除 AI 或一鍵補滿。
- 每場 10 人。真人先在等待大廳準備，由房主按「開始遊戲」進入滿版選角。選角時先選指揮、輔助或打手，再用兩側箭頭或鍵盤左右鍵切換角色，底部顯示隊友的角色，左上角可同隊聊天。全員確認後，由房主開局並進入對戰載入頁。敵隊角色於載入頁公開。單人可搭配 9 個 AI。真人依加入順序交錯分配到紅藍隊。
- 率先取得 20 擊殺者獲勝。5 分鐘到時依比分判定勝隊或平手。死亡 3 秒後嘗試復活，出生點被角色占用時會檢查附近空位。
- 結算顯示每人擊殺、死亡、助攻及有效傷害。擊殺前 8 秒內曾對同一目標造成傷害的隊友獲得助攻。兩隊各自以 2 × 擊殺＋助攻－死亡選 MVP，同分比較有效傷害，再比較擊殺與死亡。左側展示勝隊 MVP，平手時展示兩隊中排名最高的 MVP。「戰犯」授予各隊 KDA （擊殺＋助攻）÷ max(1，死亡) 最低的玩家；同分時先比較死亡數較多，再比較有效傷害較少。房主按「再玩一局」會帶現有玩家與 AI 回到同一個等待大廳，由真人重新準備，再由房主開局。比賽中離開的真人席位由 AI 接手。對戰中斷線或重新整理時，同一分頁可在 45 秒內恢復原席位，並繼續使用該場地圖。最後一名真人主動離開時房間關閉，若因斷線離開則保留 45 秒。結算畫面閒置 10 分鐘後也會關閉房間。

| --- | --- |
| W A S D | 移動 |
| 滑鼠 | 瞄準 |
| 滑鼠左鍵 | 普攻 |
| Q / C / V | 技能一／二／三 |
| Enter | 進入聊天或送出訊息 |

### 副本

每個副本各自開房及加入，房間代碼只適用於對應副本。拔旗戰、生存戰及據點戰的房間頁標題旁有玩法資訊按鈕，包含對應的遊戲畫面示意。每個副本使用伺服器生成的有邊界地圖，兩隊在分開的可通行區域出生。按 **M** 或點小地圖下方的「全圖」可查看隊友所在位置，按 **E** 可在近距離與旗幟、據點及補給互動。角色所屬的指揮、輔助或打手分類會影響生存戰及據點戰。 拔旗戰、生存戰與據點戰都能在地圖開寶箱。靠近按 **E**，道具會進入下方五格道具欄，點擊或按 **1–5** 使用。生存戰的模式補給包另外保留原有晝夜規則。

| 副本 | 勝負與操作 |
| --- | --- |
| 拔旗戰 | 紅藍兩隊各有隨機生成的領地及旗幟。靠近敵旗按 E，帶進己方領地圈得一分，先得三分獲勝。20 分鐘到時比分，同分平手。持旗者倒下或離線會掉旗，可撿回、接力或等待 20 秒自動歸位。保留 3 秒復活。 |
| 生存戰 | 24 分鐘內比較全隊平均生存時間，任一隊全員淘汰時立即結算。初始資源為 5 分鐘，普通補給及擊敗妖獸可延長，上限為 7 分鐘。資源耗盡後扣血會逐漸加重。每 3 分鐘會嘗試放置地圖可見的空投，補 150 秒資源並治療 30% 最大生命值。同一時間最多一個未開空投。第 0–8、16–24 分鐘為白天，補給皆可使用且妖獸不定時加入。第 8–16 分鐘是黑夜，部分藥材包藏有妖獸、部分道具包為立即淘汰的炸彈。指揮淘汰會使全隊定位暴露 3 分鐘，並扣除平均生存時間 1 分 30 秒。輔助淘汰則暴露全隊定位 1 分鐘。 |
| 據點戰 | 每局隨機生成 5–7 個旗形據點。未完成、也沒有標記倒數的據點每 5 分鐘重新選址。近距離互動開始標記，須累積駐守 3 分鐘。敵人進圈暫停計時，守方連續離開 12 秒則重置。對手在據點旁淘汰 3 名打手、清除全部守點者或淘汰一名輔助或指揮，即中斷倒數並可重新標記。據點成功標記後永久鎖定。全部據點標記完成或 20 分鐘時結算，以已標記數較多者獲勝。保留 3 秒復活。 |

## 開放世界

每場對戰由伺服器選擇一個 seed，生成 144 × 144 格、每格 32 px 的 4608 × 4608 世界。每局輪替抽取螢光古林、月影濕地、暮岩遺跡、霜雪松原、熔火深谷或灰垣堡壘。各場景有不同地形密度、路線和色彩。大型樹木、岩石、水域和外圈邊界阻擋行走，所有可通行區域都連通。兩隊從東西營地出發，營地中心相距 1,888 px。戰鬥畫面採近距離跟隨鏡頭。攝影範圍內沒有黑色視野遮罩或草叢隱身，夜晚以淡藍色調表示。高草可穿越，岩石與牆仍阻擋攻擊。

伺服器在開局與恢復席位時傳送該場地圖。戰鬥快照更新玩家與戰況。每個客戶端以緩動鏡頭跟隨自己的角色，視窗大小改變時會重新限制鏡頭邊界。淘汰或等待復活期間可點左側隊友頭像，定位並跟隨隊友。按 WASD 或方向鍵可回到自由移動視角。點小地圖或按 M 可開啟全圖，以右上角 × 或 Esc 關閉。小地圖下方會顯示隊友頭像、血量與倒下狀態。Canvas 只描繪可見地形區塊並重用近期區塊。角色以腳下 25 × 10 px 的 5:2 碰撞箱和地形及其他玩家碰撞，角色立繪與攻擊命中使用各自的尺寸。

## 寶箱與道具

登入玩家在對局中可靠近藏在自然景物旁的彩蛋或旅人解鎖成就。彩蛋不定時出現及換位置，沒有小地圖、全圖或 HUD 導引標記。發現的探索成就會即時入帳，擊殺和開箱等成就在正式對局結算後計入。圖鑑顯示已收藏的獎勵及金幣。

每局生成 80 個可抵達的寶箱，遠離出生營地，彼此至少相隔 160 px。品質機率為普通 70%、稀有 25%、傳說 5%。靠近後按 E 開啟，獎勵存入 5 格道具欄，按 1–5 或點擊欄位使用。道具欄已滿時寶箱保持關閉。小地圖以 1152 × 1152 px 的視窗跟隨玩家，標示範圍內的寶箱、隊友和目前看得見的敵人。已開啟的寶箱顯示暗色。

| 品質 | 道具效果 |
| --- | --- |
| 普通 | 生命藥水立即回復 15% 最大生命值、速度藥水 8 秒內移速 +18%、小型攻擊增益 8 秒內傷害 +18% |
| 稀有 | 防禦提升 10 秒內防禦 +30、強效治療立即回復 30% 最大生命值、攻擊強化 10 秒內傷害 +30% |
| 傳說 | 無敵護盾免疫傷害 3 秒、狂暴效果 7 秒內傷害 +35% 及移速 +22%、震波符文 18 秒內可按 R 施放一次半徑 112 px 的震波，基礎傷害為自身最大生命值的 5% 加基礎普攻的 80% |

治療至多回到生命上限。重複使用相同增益刷新計時，同一屬性的不同增益取最高值。陣亡移除已啟用的增益，道具欄保留到本局結束。

## 伺服器與 AI

Express 提供網頁，Socket.IO 傳輸房間事件和每秒約 20 次的權威戰鬥快照。伺服器驗證輸入、計算地圖碰撞、攻擊、投射物、生命值和勝負。Canvas 使用相同的地圖資料繪製場景，並在畫面更新時插值角色位置。

V1.1 的 AI 使用伺服器規則、網格 A*、視線和職業距離判斷。即時對戰可在 Ollama 未啟動時遊玩。V1.2 預留伺服器端 Ollama 戰術介面，模型預設為 `qwen2.5:7b`，端點預設為 `http://127.0.0.1:11434`。即時比賽目前未呼叫戰術模型。海龜湯會在 Ollama 可用時用它判斷玩家問句，超時、未啟動或忙碌時使用本地題目規則。可設定 `SOUP_OLLAMA=0` 只使用本地判斷。

房間狀態保存在單一伺服器記憶體。重啟會清空房間。開房名單可供其他玩家查看。尚無登入、房間密碼與手機觸控。
