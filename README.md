# 🎮 Game Hub — 計算機概論遊戲專題

依據《計算機概論遊戲專題大綱》建立的網頁遊戲開發原型。

## 開始執行

需要 Node.js 18+。

```bash
npm install
npm start
```

瀏覽器開啟 http://localhost:3000 。多人測試可在同一網路使用伺服器 IP，或部署至支援 WebSocket 的 Node.js 主機。

## 三個副本及完成度

| 副本 | 目前功能 | 尚未完成 |
| --- | --- | --- |
| 海龜湯（1 人） | 兩道本地題庫、提問關鍵字回覆、逐步解鎖線索、每題三次提示、揭曉答案 | 自然語言判斷、影片劇情、完整題庫 |
| 狼人殺（8/9/10/12 人） | 房間、準備、房主開始、依 PDF 人數隨機配牌、私人身分、聊天、簡化日夜投票及勝負 | 預言家、女巫、守衛等完整技能、主持人流程、依序發言、重連 |
| 團隊對抗（10/12/14 人） | 房間、準備、紅藍隊伍分配、聊天 | 職業/角色選擇、地圖、移動、戰鬥、技能、拔旗戰、生存戰、據點戰 |

**注意：** 這是第一版可運行的課堂專題骨架，不是完整遊戲。狼人殺投票目前是簡化版；團隊對抗目前只有配隊與聊天原型。多人房間保存在伺服器記憶體中，重啟後會消失。未實作身分驗證、反作弊、資料庫及正式部署安全措施。

- 後端：Node.js / Express

## PDF 與設計差異

原始規格要求：副本二、三允許多個獨立房間；完整狼人殺角色技能；團隊對抗的指揮、輔助、打手及三種對抗模式。這些是後續迭代目標。原始文件中 10 人狼人殺角色配比已依其列示實作。海龜湯故事是原型示例，不代表 PDF 附有題庫。

## 2026-11-21 優化紀錄

- 房間代碼改用加密安全亂數，避免隨機碰撞；房主離開時轉移房主。
- 增加明確離開房間事件、房間列表同步、單一玩家不得重複建立房間。
- 加入 Socket.IO 暫時斷線恢復設定；正式斷線重連及遊戲狀態恢復仍需多人實測。
- 團隊戰增加 10×7 回合制座標、上下左右移動、近距離攻擊、HP、中央據點得分及淘汰勝利條件。**三種模式目前共用簡化戰鬥邏輯，尚未依 PDF 完整實作。**
- 團隊對抗聊天僅傳送給同隊玩家；狼人殺仍使用全房聊天，**尚未做到夜間狼人私聊與完整職業技能**。
- 新增 GitHub Actions：Node.js 語法檢查與基本單元／HTTP 測試。CI 結果以 GitHub Actions 頁面為準。

### 已知限制

海龜湯仍是兩題關鍵字推理原型；狼人殺仍是簡化夜間擊殺及白天投票；團隊戰仍缺角色選擇、九角色技能、地圖視覺化與三種模式的獨立勝負規則。所有遊戲狀態儲存在記憶體中，重啟伺服器會清空。尚未進行完整 8～14 人端到端測試，請勿視為正式可上線產品。
