# 🎮 Game Hub — 計算機概論專題

網頁版三副本遊戲原型，根據課堂 PDF 規格持續開發。

## 啟動

安裝 Node.js 18+，下載專案並在專案資料夾執行：

```bash
npm install
npm start
```

瀏覽器開啟 http://localhost:3000 。同一台電腦可以開啟多個瀏覽器分頁測試多人房間。

## v0.2 功能

- **首頁**：三副本卡片、響應式深色介面。
- **海龜湯**：兩道示範故事、三次提示、線索逐段解鎖、解答。回答採關鍵字規則，並非 AI 語意判斷。
- **狼人殺**：8/9/10/12 人配置、私密角色、日夜投票、平票處理、基本陣營勝負判定。**目前為簡化版，尚未實作預言家查驗、女巫藥劑、守衛、獵人、狼王等技能**。
- **團隊對抗**：10/12/14 人分隊、指揮／輔助／打手的簡化職業、攻擊與治療、HP 和淘汰、隊伍勝負；隨機顯示三種模式名稱。**目前為簡化回合制戰鬥，尚未實作三模式的 PDF 專屬規則、九名角色技能或地圖**。
- **房間系統**：建立、加入、離開、房主轉移、房間列表、準備確認、房主開始、聊天。
- **AI 玩家**：房主在等待室點擊「＋ 加入一名 AI」補足人數，也能逐個移除。AI 自動準備；狼人殺 AI 在需要時隨機投票，團隊對抗 AI 自動攻擊。**這是規則型機器人，不是大型語言模型；不保證策略品質**。

## 使用 AI 補足房間

1. 進入狼人殺或團隊對抗，輸入暱稱並建立房間。
2. 房主在房間內按「＋ 加入一名 AI」直到人數足夠。
3. 真人玩家按「確認準備」；AI 自動準備。
4. 房主按「房主開始遊戲」。
5. AI 會依目前簡化規則自動行動。

## 注意事項

- 目前沒有帳號登入、資料庫、跨伺服器同步、持久化或真正的斷線恢復。重啟伺服器後房間消失。
- 狼人殺 AI 不會聊天推理，只有自動投票。
- 多人連線基於 Socket.IO，使用伺服器記憶體房間。架構參考 [Socket.IO Rooms](https://socket.io/docs/v4/rooms/)。
- 正式公開部署前仍需安全性與壓力測試。
- 本專案是教學原型，不能宣稱已完整符合 PDF 的全部遊戲規則。

## v0.3：本機 Ollama AI Agent（需自行安裝模型）

AI 不再使用隨機投票或隨機攻擊：每名機器人擁有**獨立私有記憶**，使用 Ollama 本機模型根據可見遊戲資訊產生 JSON 決策，由伺服器驗證合法目標後執行。狼人白天會發言，團隊對抗 AI 會在攻擊與輔助治療之間選擇。決策錯誤或 Ollama 離線時會顯示錯誤、**不會假裝已經推理**。

### Windows 安裝與啟動

1. 從 https://ollama.com/download 安裝 Ollama。
2. 開啟 CMD，下載模型：`ollama pull qwen2.5:7b`。
3. 確認 Ollama 服務正在執行（預設 http://127.0.0.1:11434）。
4. 在專案資料夾執行 `npm install` 與 `npm start`。
5. 建立房間、加入 AI、按準備後由房主開始。

可選環境變數：`OLLAMA_URL`（預設 http://127.0.0.1:11434）、`OLLAMA_MODEL`（預設 qwen2.5:7b）、`OLLAMA_TIMEOUT_MS`（預設 60000）、`AI_ARENA_INTERVAL_MS`（預設 12000）。

**重要限制：** 模型需要足夠記憶體；AI 多人決策會依序等待模型回覆，較弱電腦可能需要很長時間。AI 目前可在簡化狼人殺階段投票與發言，或在簡化團隊戰鬥中攻擊／治療；尚未加入預言家、女巫等完整技能與原始 PDF 三種團隊戰的完整地圖及勝負規則。遊戲事件記憶只保留在執行中的伺服器記憶體，不跨重啟保存。

### 驗證

`npm test` 使用模擬 Ollama 回應驗證 JSON、非法行動拒絕、記憶隔離、離線錯誤。CI 不會啟動真正的 Ollama 模型，因此**不能視為已完成本機模型整合或端對端遊戲測試**。
