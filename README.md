# 🎮 Game Hub — 計算機概論專題

網頁版三副本遊戲原型，根據課堂 PDF 規格持續開發。

## 啟動

安裝 Node.js 18+，下載專案並在專案資料夾執行：

```bash
npm install
npm start
```

瀏覽器開啟 http://localhost:3000 。同一台電腦可以開啟多個瀏覽器分頁測試多人房間。

## v0.2 功能

- **首頁**：三副本卡片、響應式深色介面。
- **海龜湯**：兩道示範故事、三次提示、線索逐段解鎖、解答。回答採關鍵字規則，並非 AI 語意判斷。
- **狼人殺**：8/9/10/12 人配置、私密角色、日夜投票、平票處理、基本陣營勝負判定。**目前為簡化版，尚未實作預言家查驗、女巫藥劑、守衛、獵人、狼王等技能**。
- **團隊對抗**：10/12/14 人分隊、指揮／輔助／打手的簡化職業、攻擊與治療、HP 和淘汰、隊伍勝負；隨機顯示三種模式名稱。**目前為簡化回合制戰鬥，尚未實作三模式的 PDF 專屬規則、九名角色技能或地圖**。
- **房間系統**：建立、加入、離開、房主轉移、房間列表、準備確認、房主開始、聊天。
- **AI 玩家**：房主在等待室點擊「＋ 加入一名 AI」補足人數，也能逐個移除。AI 自動準備；狼人殺 AI 在需要時隨機投票，團隊對抗 AI 自動攻擊。**這是規則型機器人，不是大型語言模型；不保證策略品質**。

## 使用 AI 補足房間

1. 進入狼人殺或團隊對抗，輸入暱稱並建立房間。
2. 房主在房間內按「＋ 加入一名 AI」直到人數足夠。
3. 真人玩家按「確認準備」；AI 自動準備。
4. 房主按「房主開始遊戲」。
5. AI 會依目前簡化規則自動行動。

## 注意事項

- 目前沒有帳號登入、資料庫、跨伺服器同步、持久化或真正的斷線恢復。重啟伺服器後房間消失。
- 狼人殺 AI 不會聊天推理，只有自動投票。
- 多人連線基於 Socket.IO，使用伺服器記憶體房間。架構參考 [Socket.IO Rooms](https://socket.io/docs/v4/rooms/)。
- 正式公開部署前仍需安全性與壓力測試。
- 本專案是教學原型，不能宣稱已完整符合 PDF 的全部遊戲規則。
