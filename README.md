# Game Hub

瀏覽器遊戲大廳，提供海龜湯及 5v5 即時像素風開放世界死鬥。遊戲主機需要 Node.js 18 以上，玩家以瀏覽器連線即可。

## Windows 啟動

在 CMD 輸入：

```bat
cd /d C:\Users\user\Desktop\game-hub-main
npm install
npm start
```

開啟 [http://localhost:3000](http://localhost:3000)。要讓朋友從外部連線，保持主機與遊戲伺服器運作，在另一個 CMD 視窗輸入：

```bat
cloudflared tunnel --url http://localhost:3000
```

把 Cloudflare 顯示的 HTTPS 網址分享給朋友。Quick Tunnel 若回傳 HTTP 429，可先用 localhost 驗證遊戲是否正常啟動。Ollama API 應維持在主機本地，遊戲入口使用 3000 埠。

## 遊玩

- **海龜湯**可從首頁直接開始。使用既有題庫，以「是／不是／無關」的本地關鍵字規則提供回覆。每題有三次提示，也可以換題或揭曉答案。
- **團隊對抗**由一名真人建立房間，其他真人可用房間代碼加入。房主可逐一新增、移除 AI 或一鍵補滿。
- 每場 10 人。真人先在等待大廳準備，由房主按「開始遊戲」進入滿版選角。選角時用兩側箭頭或鍵盤左右鍵切換職業，底部顯示隊友的職業，左上角可同隊聊天。全員確認後，由房主開局並進入對戰載入頁。敵隊職業於載入頁公開。單人可搭配 9 個 AI。真人依加入順序交錯分配到紅藍隊。
- 率先取得 20 擊殺者獲勝。5 分鐘到時依比分判定勝隊或平手。死亡 3 秒後嘗試復活，出生點被角色占用時會檢查附近空位。
- 結算顯示每人擊殺、死亡、助攻及有效傷害。擊殺前 8 秒內曾對同一目標造成傷害的隊友獲得助攻。MVP 從勝方選出，平手時兩隊均可入選，以 2 × 擊殺＋助攻－死亡排序，同分比較有效傷害，再比較擊殺與死亡。房主可帶全員返回房間大廳或直接再開一局。比賽中離開的真人席位由 AI 接手。對戰中斷線或重新整理時，同一分頁可在 45 秒內恢復原席位，並繼續使用該場地圖。最後一名真人主動離開時房間關閉，若因斷線離開則保留 45 秒。結算畫面閒置 10 分鐘後也會關閉房間。

| 滑鼠 | 瞄準 |
| 滑鼠左鍵 | 普攻 |

戰士、弓箭手、法師的防禦值分別為 35、12、8。所有攻擊使用同一項防禦，實際傷害為原始傷害 × 100 ÷（100＋防禦），四捨五入。設計參考 [Riot 的職業定位](https://support-leagueoflegends.riotgames.com/hc/en-us/articles/201752864-Choosing-the-Right-Champion)與 [League of Legends Wiki 的護甲公式](https://wiki.leagueoflegends.com/en-us/Armor)。普攻圈顯示最大射程，有可見敵人在範圍內且射線暢通時變綠。實際普攻仍取決於方向與冷卻。

Q 的冷卻為 5 秒。岩石阻擋遠程攻擊，投射物可越過水面。戰鬥畫面填滿瀏覽器視窗，隊伍聊天室位於左下角。戰鬥與結算時的聊天限同隊。大廳可以全房聊天。

## 開放世界

每場對戰由伺服器選擇一個 seed，生成 100 × 100 格、每格 32 px 的 3200 × 3200 世界。草地、森林、岩石、湖泊、泥土與道路以連續區域分布。大型樹木、岩石、水域和外圈邊界阻擋行走，所有可通行區域都連通。兩隊從東西營地出發，營地中心相距 1,888 px。角色視野半徑是 360 px。高草可通行，會遮蔽敵人視線，80 px 內的敵人仍能發現藏身角色。草叢不會擋住攻擊。

伺服器在開局與恢復席位時傳送該場地圖。戰鬥快照更新玩家與戰況。每個客戶端以緩動鏡頭跟隨自己的角色，視窗大小改變時會重新限制鏡頭邊界。Canvas 只描繪可見地形區塊並重用近期區塊。角色以腳下 25 × 10 px 的 5:2 碰撞箱和地形及其他玩家碰撞，角色立繪與攻擊命中使用各自的尺寸。

## 寶箱與道具

每局生成 48 個可抵達的寶箱，遠離出生營地，彼此至少相隔 160 px。品質機率為普通 70%、稀有 25%、傳說 5%。靠近後按 E 開啟，獎勵存入 5 格道具欄，按 1–5 或點擊欄位使用。道具欄已滿時寶箱保持關閉。小地圖以 800 × 800 px 的視窗跟隨玩家，標示範圍內的寶箱、隊友和目前看得見的敵人。已開啟的寶箱顯示暗色。

| 品質 | 道具效果 |
| --- | --- |
| 普通 | 生命藥水立即回復 120 HP、速度藥水 10 秒內移速 +22%、小型攻擊增益 10 秒內傷害 +15% |
| 稀有 | 防禦提升 12 秒內防禦 +40、強效治療立即回復 260 HP、攻擊強化 12 秒內傷害 +30% |
| 傳說 | 無敵護盾免疫傷害 4 秒、狂暴效果 8 秒內傷害 +40% 及移速 +30%、震波符文 18 秒內可按 R 施放一次範圍震波 |

治療至多回到生命上限。重複使用相同增益刷新計時，同一屬性的不同增益取最高值。陣亡移除已啟用的增益，道具欄保留到本局結束。

## 伺服器與 AI

Express 提供網頁，Socket.IO 傳輸房間事件和每秒約 20 次的權威戰鬥快照。伺服器驗證輸入、計算地圖碰撞、攻擊、投射物、生命值和勝負。Canvas 使用相同的地圖資料繪製場景，並在畫面更新時插值角色位置。

V1.1 的 AI 使用伺服器規則、網格 A*、視線和職業距離判斷。即時對戰可在 Ollama 未啟動時遊玩。V1.2 預留伺服器端 Ollama 戰術介面，模型預設為 `qwen2.5:7b`，端點預設為 `http://127.0.0.1:11434`。即時比賽目前未呼叫戰術模型。

房間狀態保存在單一伺服器記憶體。重啟會清空房間。開房名單可供其他玩家查看。尚無登入、房間密碼與手機觸控。

## 測試

```bat
npm test
node --check server.js
node --check arena/combat.js
node --check arena/bots.js
node --check ai/ollama-agent.js
node --check public/app.js
node --check public/arena-renderer.js
```

測試涵蓋 HTTP、Socket.IO 雙客戶端、房間權限、座位、分隊、同步、隊伍聊天、離線 AI 接手、再開一局，以及碰撞、技能、傷害、復活與勝負判定。
